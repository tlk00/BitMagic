# Historical horizontal/BWT experiments

The per-experiment collection runners, their coupled reports, one-off source
editing scripts, and source snapshots have been retired. Findings and historical
commands in the Markdown files are retained as research records; those commands
are not a supported execution interface.

Use [the current preset validation harness](../current/README.md) for Gov2 runs.
The shared progress renderer now lives in `../current/progress_console.py`.

The C++ fixtures and build-only test scripts remain for focused codec coverage.
