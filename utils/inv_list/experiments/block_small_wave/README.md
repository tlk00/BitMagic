# Retired small-wave experiment

The 8/16-bit occupancy and BIC map/residual experiments have been retired.
Their code, binaries, tests, build targets and execution harnesses were removed.
[Results and limitations](RESULTS.md) are retained for future design work.
Generic opcode size and bits-per-original-ID profiling remains available in
[opcode_profile](../opcode_profile/README.md).
